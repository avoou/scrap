There are 3 version of web scraping: 
    - using python3 with beautifulsoup (krossy.py);
    - using Perfect with beautifulsoup (krossy-prefect.py);
    - using Scrapy framework (/krossy_project).

To run first one:
    - python krossy.py

To run second one:
    - python krossy_prefect.py

To run Scrapy project:
    - cd krossy_project/
    - run command: "scrapy crawl boots"
